# EcoLink — Free PWA Prototype

A static, mobile-first EcoLink prototype for community-based ecotourism around the Sundarbans.

## Included
- Home / project story
- Dacope + Mongla pilot areas
- 5 EcoLink components
- Eco experiences
- Community guides
- Accommodation
- Local enterprise marketplace
- Environmental monitoring concept dashboard
- Booking/request form
- Installable PWA
- Offline cache for the core app

## Important
This is a front-end prototype. The request form saves submissions only in the visitor's browser using localStorage. For real bookings, connect it to a database or form service.

## Publish on GitHub Pages
1. Create a public GitHub repository, e.g. `ecolink-app`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.
7. Wait for GitHub Pages to publish. Your site will use a GitHub Pages URL.

GitHub Pages documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages
